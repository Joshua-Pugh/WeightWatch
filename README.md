# 🏋️ WeightWatch
**A personal health tracking mobile app built with Java and Android Studio.**

---

## 📱 Overview
**WeightWatch** is a mobile application that helps users **track weight goals**, **log progress**, and **monitor long-term trends**.  
It’s designed with a clean and responsive interface, offering persistent data storage and intuitive navigation.

---

## ⚙️ Tech Stack
- **Java** – Core language for app logic  
- **Android Studio** – UI design, testing, and build management  
- **XML** – Layouts and UI components  
- **SQLite / SharedPreferences** – Local data persistence  

---

## 🚀 Features
- 📊 **Track & visualize weight goals**  
- 💾 **Persistent local storage** — data saved between sessions  
- ⚡ **Lightweight UI** built for speed and usability  
- 🧩 **Expandable architecture** for adding future features like BMI tracking or calorie logs
